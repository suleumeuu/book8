C++ ТІЛІНДЕ МАШИНАҒА БАҒЫТТАЛҒАН БАҒДАРЛАМАЛАУ

Алғы сөз

«С++ тілінде машинаға бағытталған бағдарламалау» электрондық оқулық білім алушылардың С++ тілінде бағдарламалар құру, деректерді өңдеу және компьютер жадымен жұмыс істеу негіздерін меңгеруіне арналған.

Құрастырушы: Найзағараева А.А. С.Сейфуллин атындағы Қазақ агротехникалық зерттеу университеті, «Ақпараттық жүйелер» білім беру бағдарламалары тобының аға оқытушысы, PhD.

Дәріс №1. Объектіге бағытталған программалау технологиясы. C++ тілі

Дәрістің мақсаты: объектіге бағытталған программалау технологиясы түсініктерімен таныстыру.

Дәрістің мазмұны: класс ұғымы және оның элементтері. С++ тілі ортасының артықшылықтары.

Нақты әлемнің объектілеріне еліктеуді C++ немесе Java сияқты объектіге бағытталған программалау тілдерінде кластарды анықтау арқылы жүзеге асыруға болады. Класс деректер мүшелері мен әдістер мүшелерінен тұрады...

Дәріс №2. Деректер типінің сілтемелері

Дәрістің мақсаты: объектіге сілтемені қолданудың әдістерін ұғындыру.

С++ тілінде нұсқауышқа туыс элемент – сілтеме (reference) бар. Сілтеме барлық жағдайда жасырын нұсқауыш болып, оны кезкелген мақсат үшін айнымалының тағы бір аты ретінде қолдануға болады...

№1 Зертханалық жұмыс. Есептелетін және есептелмейтін түріндегі қарапайым типтік есептер

Жұмыс мақсаты: Студенттерді енгізу – шығару операторларын пайдаланып, С++ тілінде қарапайым программалар жазуға үйрету.

#include <stdio.h>
main()
{
    float a, b, c;
    printf("Екі санды енгіз: ");
    scanf("%f%f", &a, &b);
    c = a + b;
    printf("Қосындысы c=%f\n", c);
}
